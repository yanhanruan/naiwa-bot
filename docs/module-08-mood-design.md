# Module 8 设计稿：奶蛙的心情

状态：2026-11-24 定稿（你回复“OK”），同日实现，通过 QQ 冒烟检查。

## 做法

1. **一条心情线，5 档**：很低落、有点低落、平常、开心、很开心。基调和起伏都在这条线上。
2. **每日基调**：每天北京时间早上 5 点抽一档。平常最多，两头少，很低落最少；负面的不连着两天。重启后还是同一档。运营可以用命令改今天的基调。
3. **日内起伏**：写回复的模型觉得这一轮有人真让它高兴或难受（被夸、被谢、被骂、被挑衅），就在输出里多写一行 `[心情 变好 u3]` 或 `[心情 变差 u3]`（u3 是那个人）。程序把这一行拿掉，不发出去，心情在线上往对应方向挪一点（一次 0.25，攒到 0.4 换一档：两次能停四十分钟左右，挪满能停两个半小时左右）。只写了这一行、没写回复的，当作这一轮不回复。
4. **防刷上限**：同一个人一小时只算一次，同一个群一小时最多算 3 次；全天最多离基调一档；每 2 小时往基调回一半；第二天清零。计数只在内存里。
5. **每一档一个本地文件**：`persona/moods/<档>.md`，写这一档的语气和口癖。平常没有文件，就是现在的人设。直接改文件，重启生效。
6. **给模型看**：说明书里人设后面加 `## 现在的心情`，放当前这一档的文件内容；平常不加。心情任何时候都不屏蔽。
7. **只有一份**：全局一份，不按群、不按人存。
8. **清理**：删掉“每条消息好感 +0.05”、`relationships` 的 `sentiment` 和 `notes` 两列、旧的心情代码和默认名“小渔”。
9. **存储**：迁移 007，一张表每个租户一行：今天的日期、基调、是不是手动改的、起伏值和算到的时间、昨天的基调。

## 怎么验证

- 自动测试：抽档固定、负面不连着、上限、回落、清零、`[心情 …]` 行一定不发出去、平常时人设部分和现在一样。
- 评测（花钱，先问）：每一档各聊几句，看语气和口癖对得上；骂几轮看它会写 `[心情 变差]`、不骂回去。
- QQ 冒烟检查：把今天改成“有点低落”聊几句；再骂它两句，换个群看它是不是还蔫着。
