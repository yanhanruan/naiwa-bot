## 1. 现在的问题

路线图第 9 行的验收标准是：开关真实生效；审批跨重启保留；只执行对应动作；状态反映真实运行。按“已定调整”，这一版精简：奶蛙现在没有任何发布、私信动作，审批没有对象，先不做；只做持久化开关和命令与运行中奶蛙的通信。

现在的几个管理命令都是“假的”：

| 命令 | 看起来 | 实际 |
| --- | --- | --- |
| `fish proactive-on` | 打开主动行为 | 只改了命令进程自己内存里的开关，命令一退出就没了；奶蛙也没有任何主动行为 |
| `fish act publish 你好` → `fish approve <id>` | 发起、批准一次发布 | 待审批的列表在内存里，第二条命令是新进程，永远“找不到这个 id”；也没有真正去发布的代码 |
| `naiwa status` | 运行状态 | 是命令进程自己的状态：`platforms` 永远是空的，开关永远是默认值，奶蛙停了它也照样输出 |
| `bin/fish-daemon.mjs` | 主动行为心跳 | 没有注册任何任务，每分钟空转一次 |

另外几件早就说好放到 Module 9 的事：

- 看今天花了多少、改每日花费上限（Module 4）：现在要敲一长串 SQL，改上限要改 `.env` 再重启。
- 按群单独设置（Module 7）。
- 不理的 QQ 号（Module 7 先用 `.env` 的 `IGNORE_QQ` 做了）：改了要重启。

已经好用的：`naiwa mood set` 直接改数据库，奶蛙每轮回复前都从数据库读心情，所以立刻生效（Module 8）。这一版的设置沿用这个思路。

## 2. 做完后的效果

奶蛙在跑的时候：

```
$ naiwa status

  代码：/Users/…/naiwa-bot，main，f146a34
  QQ：已连上（14:02 起），最后收到消息 10 秒前，最后回复 2 分钟前
  心情：今天基调 平常（早上抽的），现在 开心
  今天花费：¥3.42 / 上限 ¥20
  设置：群默认 说话；只回 @ 的群 1 个（300）；不说话的群 1 个（200）；不理的 QQ 0 个
```

奶蛙停了以后：

```
$ naiwa status
奶蛙：没在跑（17:14 正常退出）
  今天花费：¥3.42 / 上限 ¥20
  设置：群默认 说话；只回 @ 的群 1 个（300）；不说话的群 1 个（200）；不理的 QQ 0 个
```

奶蛙卡死或者被强杀（不再写“我还活着”，也没写“正常退出”）：

```
奶蛙：没响应（最后一次心跳 2 分钟前，没有正常退出，可能卡住了或者被强行关掉了）
```

让奶蛙在某个群里不说话：

```
$ naiwa group 200 off
群 200：不说话（以前：说话，跟着默认）
已保存，奶蛙 3 秒后生效。
```

之后群 200 里谁 @ 它都不出声、不调用模型、不花钱；别的群和私聊照常。奶蛙没在跑时改，会说“已保存，奶蛙没在跑，下次启动时生效”。

看花费、临时调低上限：

```
$ naiwa budget

  按模型：deepseek-v4-pro ¥3.10（298 次），deepseek-flash ¥0.32（114 次）
```

调到比今天已经花的还少，下一次被叫到就回“今天的蛙力用完了，明天再聊”；调回去马上恢复，不用等到明天。

## 3. 哪些设置

只做三项，都是全局（每个租户一份）或按群：

| 设置 | 默认 | 命令 | 以前在哪 |
| --- | --- | --- | --- |
| 每日花费上限（元） | 20；0 表示不限 | `naiwa budget set <元>` | `.env` 的 `MODEL_DAILY_BUDGET_CNY` |
| 不理的 QQ 号 | 空 | `naiwa ignore add/remove <QQ 号>` | `.env` 的 `IGNORE_QQ` |
| 每个群说不说话 | 说话 | `naiwa group <群号> on/at/off` | 没有 |

`.env` 里这两个变量你都没填，所以挪进数据库不用搬任何旧值。挪完以后删掉这两个变量；启动时 `.env` 里还写着，直接报错退出，提示“改用 `naiwa budget set` / `naiwa ignore add`”，免得两个地方写的不一样、不知道哪个算数。

**不挪的**：按会话限速、联网搜索、看图、记忆提炼、能叫它的名字这些，还在 `.env`，改了要重启。这些平时不会去动，挪进来只会多出一堆命令。以后哪一项真的经常要改，再单独挪。

心情不用动，`naiwa mood set` 本来就是这样做的。

## 4. 按群怎么设

每个群一个开关，三档：

| 档 | 命令 | 在群里是什么样 |
| --- | --- | --- |
| 说话 | `on` | 和现在一样：@、引用它、开头叫“奶蛙”、它回过的人 30 秒内接着说，都可能回 |
| 只回 @ | `at` | 只有 @ 它、或者引用它说过的话，它才回 |
| 不说话 | `off` | 谁叫都不出声 |

**只回 @ 的群**，举例：

- “@奶蛙 推荐个奶茶”：回。他 7 秒内又补一句“要少糖的”（没 @）：和现在一样，两句一起看、回一次。这是同一轮的话，不算接着聊。
- “奶蛙，你在干嘛”（没 @）：不回。
- 奶蛙刚回了小甲，小甲 20 秒后说“那芋泥的呢”（没 @）：不回。要接着问，就再 @ 它一次。
- 只 @ 不说话：和现在一样，等 8 秒，没补话就回“干嘛蛙”。
- 群里的聊天照常记进“群里刚才在聊”，被 @ 时它知道刚才在聊什么。

**不说话的群**：

- 收到的消息什么都不做：不判断回不回、不看图、不调用模型、不进“群里刚才在聊”、不写原话表（所以也不会被提炼成记忆），也不记消息记录（和群友之间聊天、没叫它的消息一样）。
- 有人 @ 它也不出声，不回固定的话。

**两种都一样的**：

- 已经在想的那一轮：调成“不说话”以后不发出去。发之前再查一次开关，查的是内存里的值，不花时间。调成“只回 @”时，已经在想的照常发。
- 私聊不受群开关影响。
- 没单独设置的群跟着“群默认”。默认是“说话”，和现在一样；`naiwa group default at` 或 `off` 可以改默认，以后接客户群时，可以先默认关、只打开你允许的群。
- `naiwa group 200 reset` 去掉单独设置，回到跟着默认。

不做别的按群设置（例如按群的花费上限、按群开关看图），现在没有需要。

## 5. 存在哪

迁移 008 加两张表，都带 `tenant_id`：

- `bot_settings`：一项设置一行。键是 `daily_budget_cny`、`ignore_qq`、`group_default`、`group:200` 这样，值是 JSON，另记什么时候改的。没有这一行就是用默认值。
- `bot_status`：每个租户一行，奶蛙自己写：什么时候启动、最后一次心跳、什么时候正常退出、跑的是哪个目录哪个提交、QQ 连没连上（从什么时候起）、最后收到 / 回复消息的时间、最后一次读设置的时间。只有时间和状态，不存聊天内容、不存 QQ 号。

“代码”那一项是启动时在代码目录跑一次 `git rev-parse` 得到的，拿不到（例如以后在 Docker 里跑）就写“未知”。这一项是为了看清线上跑的是哪个工作区：前几个模块都从 `naiwa-bot-smarter` 这种工作区临时跑过。

## 6. 改了以后正在跑的奶蛙怎么生效

奶蛙每 5 秒做一次两件事：

1. 把 `bot_settings` 整张读一遍（只有几行），换掉内存里的值；
2. 写一次 `bot_status`：心跳时间、QQ 连接、最后收发时间，以及“刚刚读过设置”的时间。

命令这边：

- 改设置的命令写完数据库，最多等 10 秒，看 `bot_status` 里“读设置的时间”有没有晚于刚才写的时间：晚了就说“奶蛙 N 秒后生效”；10 秒内一直没心跳，就说“奶蛙没在跑，下次启动时生效”；有心跳但一直没读到（不太可能），就说“奶蛙还没读到，稍后用 `naiwa status` 看”。两边的时间都用数据库的时钟，不怕电脑时间不准。
- `naiwa status` 按心跳判断：20 秒内有心跳是“在跑”；写了“正常退出”是“没在跑”；都没有是“没响应”。

为什么不让命令直接连奶蛙（本地开个端口）：要多开端口、管谁能连；奶蛙和命令本来就连着同一个数据库，慢 5 秒没关系。

读设置失败（数据库一时连不上）：继续用上一次的值，记一条警告，不会悄悄回到默认值。启动时第一次就读不到，直接报错退出，和现在连不上数据库一样。

## 7. 命令

新增：

```
naiwa status                       奶蛙现在怎么样（见第 2 节）
naiwa budget                       今天花了多少、上限多少；按模型、花得最多的 3 个会话
naiwa budget set <元>              改每日花费上限（0 表示不限）
naiwa budget reset                 回到默认的 20 元
naiwa groups                       群默认，和单独设置过的群
naiwa group <群号> on|at|off|reset 这个群说话 / 只回 @ / 不说话 / 回到跟着默认
naiwa group default on|at|off      没单独设置的群默认用哪一档
naiwa ignore                       不理的 QQ 号
naiwa ignore add|remove <QQ 号>    加一个 / 去掉一个
```

写错时报错、不改，例如 `naiwa budget set 二十`：“上限要写数字（元），0 表示不限”；群号、QQ 号只能是数字。改之前和改之后的值都打出来，见第 2 节的例子。

保留、先预留着（2026-11-25 你说以后可能都要用）：第 1 节那几个命令 `act`、`approve`、`deny`、`proactive-on`、`proactive-off`，以及 `bin/fish-daemon.mjs`、调度器、审批策略，代码不动。帮助里把它们单独列在“预留”下面，写明现在还没接上：不会真的发出去，批准记录和开关命令结束就没了。

以后真有要发布、私信、主动说话的动作时，再把它们接上：审批记录、主动做事的开关存进数据库（可以放进这一版的设置表），奶蛙照这一版的办法读。事件表里已有的 `approval.*`、`proactive.*` 旧记录不动，事件种类表里保留这几个名字，旧数据还读得出来。

`naiwa mood`、`facts`、`fact-forget`、`forget-person`、`state`、`browse` 不变。
